# Privacy policy

Effective date: July 24, 2026

Bob and Mary's Retirement Meal Planner is designed to work locally without an
account. It does not contain advertising, analytics, tracking, or a developer
operated cloud synchronization service.

## Information stored by the planner

The planner can store recipes, meal plans, grocery lists, refrigerator,
freezer, and pantry inventory, receipt details, store names, item numbers,
prices, spending history, cooking progress, settings, and photos that the user
chooses to attach. This information stays in the planner data on the device or
thumb drive unless the user deliberately exports or shares a backup.

Receipt photographs and PDF files are read locally by the bundled PDF and text
recognition software. Selecting a file does not upload that source file to the
project developer. Corrected receipt details are saved only when the user
accepts them. A photo intentionally attached to a recipe is stored as part of
the planner data and its backups.

## Optional internet use

The main planner works offline. Internet access is used only when the user
chooses an online feature:

- Recipe search sends the typed recipe name or main ingredient to TheMealDB and
  downloads matching public recipe information and images.
- Import from a recipe link requests the public web address chosen by the user.
  That recipe website receives a normal web request.

Those providers process requests under their own privacy policies. The planner
does not send household inventory, grocery history, receipt contents, meal
spending, or attached personal photos to those providers.

## Backups and control

Automatic Android cloud backup and Android device-transfer backup are disabled.
The user controls data movement through the planner's visible export, import,
backup, and restore tools. Thumb-drive automatic backups remain on that thumb
drive.

Users can edit or delete planner entries from the app. Uninstalling the Android
app or clearing its storage removes the local Android copy. Thumb-drive data and
backup files remain on the drive until the user removes them.

## Permissions

The Android app requests internet access for the optional online features. It
does not request location, contacts, microphone, broad photo-library, or broad
storage permissions. Files and pictures are selected through system file
pickers when the user asks to import them.

## Questions

Privacy questions and requests can be submitted through the project's
