Supperloom Meal Planner

Double-click "Start Meal Planner.bat" to run it as a small local website.
This is the best way to use it because it saves your recipes and food lists
to planner-data.json on this thumb drive.

If you want to view it from an iPhone or Android phone while the thumb drive is
plugged into a Windows computer, double-click "Start Meal Planner for Phones.bat".
The window will show a phone address to type into the phone browser while both
devices are on the same home Wi-Fi.

You can also open index.html directly in a web browser, but that fallback only
saves inside that computer's browser.

What it does:
- Save recipes with ingredients and prep instructions.
- Build a simple starter meal by clicking through choices like beef, chicken, pork, meatloaf, steak, or roast.
- Change the Build a meal choices, rename them, add new ones, and edit the meal preview ingredients. These changes are remembered.
- Change the number of people eating and ingredient amounts update instantly.
- Print a one-page meal sheet with the scaled ingredients and prep notes.
- Paste Walmart, Publix, Aldi, or other grocery order text into the food list and it sorts groceries into Refrigerator or Pantry.
- Upload text or CSV grocery files. The planner tries to save item names, prices, store names, and item numbers such as SKU, UPC, barcode, or item #.
- Choose Computer, iPhone, or Android view from the top of the page.
- Export recipes and pantry data to a backup file, then import it on another computer.

PDF and photo receipt note:
For now, copy the text out of a PDF or photo receipt first, then paste that text into
the grocery order box. Full offline PDF/photo reading can be added later, but it is
a bigger feature than plain text importing.

Thumb drive note:
When started with "Start Meal Planner.bat", your recipes and refrigerator/pantry
food lists are saved to planner-data.json in this same folder. That lets the data
travel with the thumb drive from computer to computer.

Use Export recipes as an extra backup whenever you want a spare copy.

Phone note:
The iPhone and Android buttons make the page easier to use on a phone. For the
phone to use the same thumb-drive database, the meal planner still needs to be
running from the thumb drive on a Windows computer. A full phone-only offline
version can be added later, but it will need its own save-and-sync setup.

Auto-start note:
Modern Windows usually blocks USB drives from automatically running programs when they
are plugged in. That is why this folder includes a one-click launcher instead.
