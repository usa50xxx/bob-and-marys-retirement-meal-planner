# Bob and Mary's Retirement Meal Planner v1.0.0

This is the first stable release of Bob and Mary's private, offline-first meal
planner for a Windows thumb drive and Android phones.

## Choose your download

- **Android phone:** install `Bob-and-Marys-Meal-Planner-v1.0.0.apk`.
- **Windows thumb drive:** extract
  `Bob-and-Marys-Meal-Planner-Thumb-Drive-v1.0.0.zip` onto the thumb drive.
- **Google Play testing:** upload `Bob-and-Marys-Meal-Planner-v1.0.0.aab` to
  Play Console. The AAB is not installed directly on a phone.
- Use `SHA256SUMS.txt` to verify that a downloaded file is complete.

## Back up before upgrading

1. Open **Home**.
2. Open **Backups and recovery** near the bottom of the page.
3. Select **Create backup now**.
4. Select **Export backup** and keep that JSON file somewhere other than the
   app or thumb drive being updated.

On Android, install the new APK over the existing app. **Do not uninstall the
old app or clear its storage first**, because either action removes its local
planner data. The signed upgrade must preserve recipes, inventory, meal plans,
photos, and spending history.

For a thumb-drive update, close the meal-planner server before replacing the
application files. Keep the existing `planner-data.json` and `backups` folder.
The release package does not contain or overwrite personal planner data.

## What is included

- Recipe serving changes that recalculate ingredient quantities.
- A weekly meal calendar and one combined grocery list.
- **Have / Need / Buy** calculations using refrigerator, freezer, and pantry
  quantities.
- Receipt and grocery-order review with item prices, stores, and item numbers.
- PDF and photograph reading for receipts and recipes, with approval before
  anything is saved.
- Meal-cost and per-person estimates with a spending calendar.
- Picture-based meal choices and a visual Recipe Rolodex.
- A guided cooking screen with ingredient checkoff, one step at a time,
  multiple timers, and saved cooking progress.
- Best-by dates, food-to-use-soon suggestions, inventory subtraction after
  cooking, and Undo.
- Local backups, interrupted-save recovery, and backup import/export.
- Computer, iPhone browser, and Android layouts.

## Privacy and offline use

Recipes, meal photos, grocery history, prices, inventory, and plans are kept on
the device or thumb drive. The core planner, inventory, grocery list, receipt
reading, recipe-photo reading, and cooking guide work without an account.

Internet access is used only for features that need it, such as searching the
online recipe provider or reading a public recipe website link. There is no
automatic household cloud sync.

## Known limitations

- iPhone support is a browser layout; this release does not include a native
  iOS app.
- Windows does not automatically run programs from an inserted USB drive.
  Start the thumb-drive planner by double-clicking its start file.
- Receipt and recipe OCR can misread unusual fonts, shadows, folds, or blurry
  photographs. Always check the review screen before approving imported data.
- Online recipe search requires an internet connection and availability from
  the recipe provider.
- Data does not synchronize automatically between devices. Use Export backup
  and Import backup to move it.
- Shared household accounts, barcode scanning, nutrition profiles, allergy
  profiles, and store checkout are planned for later releases.

## Release verification

Before this draft is published, the exact signed files must pass Android lint,
the complete browser suite, Android 7 and current-Android device tests, a
data-preserving upgrade test, offline recipe-photo OCR, backup and recovery
tests, automated WCAG A/AA checks, signature verification, image-license
clearance, and Play Console pre-launch review.

After downloading a published release file, its GitHub build provenance can be
verified with:

```powershell
gh attestation verify RELEASE-FILE.apk -R usa50xxx/bob-and-marys-retirement-meal-planner
```
